# Cambios v34 - Tablas Admin y recordatorios

Cambios aplicados:
1. Gestión de Reservas ahora muestra primero las reservas más nuevas y luego las antiguas.
2. Gestión de Reservas incorpora filtros para cada columna:
   - Fecha / Hora
   - Servicio
   - Sucursal
   - Masoterapeuta
   - Cliente / Contacto
   - Comentarios
   - Estado
3. Gestión de Contactos usa las mismas dimensiones, tamaño de tabla y letras que Gestión de Reservas.
4. Gestión de Recordatorios usa las mismas dimensiones, tamaño de tabla, letras y botones que Gestión de Reservas.
5. Se eliminó la columna "Tipo" de Gestión de Recordatorios.
6. Botón de WhatsApp reducido y renombrado a "WhatsApp".
7. Link de anamnesis actualizado a:
   https://forms.gle/T5EzAJLUsmfUsLSW6

No requiere nueva migración en Supabase.
